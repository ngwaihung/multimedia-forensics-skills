# Forensic enhancement

For visual work consult [SWGDE *Image Processing Guidelines*, 15-M-002-1.0](https://www.swgde.org/documents/published-complete-listing/15-m-002-swgde-image-processing-guidelines/); for audio use [SWGDE *Best Practices for Enhancement of Digital Audio*, 20-A-001-2.0](https://www.swgde.org/documents/published-complete-listing/20-a-001-2/). Check the current versions and apply local validated procedures. These documents guide process and documentation, not a claim that a particular filter can recover missing information.

Enhancement helps perception and measurement but cannot restore information that was never recorded. Define the question and preserve the unaltered evidence. Work from a hashed copy, retain the source and intermediate outputs, and document the full order of operations, parameters, software versions, color space, sampling, and region coordinates.

Use the least transformative operation that addresses the question: exposure/levels, crop, rotation, channel view, denoise, deblur, stabilization, or speed change. Compare the result beside the source at matched coordinates and clearly label every enhanced exhibit. Keep interpolation, sharpening halos, hallucinated detail, and generative fill from being mistaken for source content. Generative restoration can be used to explore a hypothesis but never to assert a recovered face, word, license plate, or other evidential detail without independent support.

Record whether the result is for illustration, measurement, or investigative lead. For measurements, validate that the transformation preserves the property being measured and quantify uncertainty introduced by scaling or filtering. Include the original or a direct link to it in the report so a reviewer can assess the transformation.

For audio, assess waveform, channels, spectrum, spectrogram, and critical listening before choosing a chain. Address the observed defect with a documented operation, compare each output to its input, and inspect the removed residual for lost target signal. Keep uncompressed intermediates when moving between applications. Compare final and unprocessed recordings after a listening break; over-processing can reduce intelligibility or alter speech cues. For video and images, document interpolation, deinterlacing, color-space conversion, pixel-aspect correction, and aspect-ratio changes because display differences can mimic detail or geometry. Never present an AI-generated reconstruction as a source observation.
