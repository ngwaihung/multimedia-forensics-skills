# Synthetic-media examination

No universal detector is validated by a SWGDE authentication document. Apply the relevant [SWGDE image-authentication guidance, 18-I-001-2.0](https://www.swgde.org/wp-content/uploads/2025/03/2025-03-03-Best-Practices-for-Image-Authentication-18-I-001-2.0.pdf), [video-authentication guidance, 23-V-001-1.2](https://www.swgde.org/wp-content/uploads/2026/02/23-V-001-1.2-Best-Practices-for-Digital-Video-Authentication.pdf), or [audio-authentication guidance, 15-A-001-1.3](https://www.swgde.org/documents/published-complete-listing/15-a-001-swgde-best-practices-for-digital-audio-authentication/) to the file and proposition. For detector evaluation and provenance concepts, consult [NIST's synthetic-content transparency overview](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.100-4.pdf) and the [C2PA technical specifications](https://spec.c2pa.org/specifications/).

Define the proposition: wholly generated media, altered region or voice, face swap, reenactment, or ordinary processing. These require different tests. First seek provenance: source file, capture chain, signed content credentials if present, edit history, and independent earlier copies. Verify signatures and trust chains rather than treating a displayed credential badge as self-authenticating. Missing credentials are common and do not imply generation.

Inspect modality-specific consistency and temporal behavior before selecting detectors. For faces, voices, and speech, account for compression, low resolution, language, demographics, capture conditions, and post-processing. Use a detector only if its model version, intended domain, evaluation population, calibration, and relevant false-positive/false-negative behavior are known. Preserve raw scores, thresholds, inputs, preprocessing, and model settings. A score is conditional on a model and dataset; it is not a probability that the submitted item is fake unless calibrated for this setting.

Prefer independent evidence: verifiable provenance, original raw/camera files, synchronized multi-camera material, distinctive generation artifacts supported by a validated method, or materially independent detectors. Multiple detectors trained on similar data or the same compressed derivative are not independent corroboration. Do not claim a particular generator, prompt, or actor from generic artifacts. If domain shift or unavailable validation prevents a reliable opinion, report the observed features and an inconclusive classification.

For model use, retain the code commit, checkpoint hash, training/evaluation domain, input preparation, face detector or cropper, frame selection, threshold, raw outputs, and hardware/software versions. Use independent, case-relevant authentic and synthetic controls; measure performance at the selected operating point. Screen for errors correlated with resolution, age/skin-tone/lighting, language or accent, codec, and export path as relevant. A benchmark AUC or raw softmax score is not a case probability. Preserve failed detections and unstable scores rather than averaging them away. A model should never be the sole basis of a court-facing conclusion.
